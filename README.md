## Featured Projects

### 🚦 Gainesville Traffic Crash Analysis

**Python | Pandas | Statistical Analysis | Logistic Regression | ArcGIS**

Analyzed more than **58,000 Gainesville traffic crash records from 2015–2025** to identify crash trends, fatality risks, vulnerable-road-user patterns, peak crash periods, and high-risk corridors.

#### My Contributions

- Cleaned and transformed raw crash records into an analysis-ready dataset.
- Engineered crash type, severity, fatality, time-of-day, and intersection features.
- Classified crashes involving pedestrians, cyclists, multiple vulnerable users, and motor vehicles.
- Conducted a **Chi-square test of independence** to evaluate the relationship between crash type and fatality outcomes.
- Developed and interpreted **logistic regression models** to assess predictors of fatal crashes.
- Created annual, hourly, statistical, and geographic visualizations.
- Identified recurring high-risk corridors and peak crash periods.
- Translated analytical findings into transportation-safety recommendations focused on pedestrians and cyclists.

### 🤖 Financial Document Intelligence Application

**Python | LangChain | RAG | FAISS | ChromaDB | LLM Evaluation**

Developed an AI-powered document Q&A application that retrieves relevant information from financial documents and generates context-based answers.

#### Key Contributions

- Architected a Python-based Retrieval-Augmented Generation pipeline.
- Implemented four processing strategies: **Stuff, Map Reduce, Map Re-rank, and Refine**.
- Benchmarked **21 model configurations** across text splitters, embedding models, retrieval methods, vector stores, and chunk sizes.
- Improved response accuracy from approximately **65% to more than 90%**.
- Identified top-performing configurations that produced correct responses with zero incorrect outputs during evaluation.
- Reduced manual document-review effort through automated information retrieval.

**Python | Streamlit | Pandas | Operational Analytics | Data Visualization**
